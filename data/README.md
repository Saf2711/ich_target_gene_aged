# Data

## Processed files included

### `processed/genomewide_brain_aging_gene_screen.csv`

Complete genome-wide summary containing 28,250 unique gene labels.

### `processed/all_downward_genes.csv`

Union of the high-confidence, moderate, and directional age-decline groups,
containing 9,818 genes.

## Raw files

The 13 Age Effect Explorer CNS tables are downloaded into:

```text
data/raw/age_effect_explorer/
```

using:

```bash
aged-ich download-aging-data
```
